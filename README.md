# Rancho Brilho do Sol

Site do espaço em Juazeiro, Bahia, com abertura fotográfica, seleção de evento, cenas dos ambientes, galeria ampliável e formulário de orçamento pelo WhatsApp. Layout baseado na última versão do La Bella Luna.

## Publicar na Vercel

Importe este repositório em https://vercel.com/new e clique em Deploy.

- Framework: Other
- Root Directory: raiz do repositório
- Build Command: `npm run build`
- Output Directory: `dist`

A configuração está em `vercel.json`. As fotos e fontes estão incluídas. Não há dependências ou variáveis de ambiente necessárias.

## Arquivos

- `dist/index.html`: conteúdo e formulário
- `dist/style.css`: layout e responsividade
- `dist/script.js`: menu, seleção de evento, galeria e mensagem do WhatsApp
- `dist/assets`: fotografias, marca e fontes

O formulário reúne nome, data, tipo de evento e número de convidados. O visitante revisa e envia a mensagem no WhatsApp; a equipe confirma a disponibilidade.
